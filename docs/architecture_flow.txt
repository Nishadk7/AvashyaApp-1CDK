2. AWS ROUTE 53 (PUBLIC HOSTED ZONE)
   - Network Location: AWS Global Edge Network (Outside VPC)
   - Protocol: DNS (UDP/TCP Port 53)
   - Action: Resolves domain name via Apex & WWW Alias A-Records pointing directly to CloudFront distribution endpoint.

3. AMAZON CLOUDFRONT (CONTENT DELIVERY NETWORK)
   - Network Location: AWS Global Edge Network (600+ Edge Locations worldwide)
   - Protocol: HTTPS (TLS 1.2/1.3 over TCP Port 443)
   - Security: Origin Access Control (OAC) with SigV4 signing
   - Routing Logic:
     a) Default Behavior (/*): Routes static asset requests to S3 Web Frontend Bucket.
     b) API Behavior (/api/*): Forwards dynamic REST API requests to Application Load Balancer (ALB).

4. AMAZON S3 WEB FRONTEND BUCKET (Static Assets)
   - Bucket Name: nishadinternsip-avashya-web-frontend-2026
   - Network Location: AWS S3 Regional Storage Service (100% Block Public Access)
   - Protocol: HTTPS (AWS REST API / SigV4 GET requests over TLS Port 443)
   - Action: Delivers static HTML, CSS, JavaScript, and asset files to CloudFront edge for browser rendering.

5. APPLICATION LOAD BALANCER (ALB)
   - Load Balancer Name: nishadinternsip-alb
   - Network Location: AWS VPC - Public Subnets (AZ-1: 10.0.1.0/24 | AZ-2: 10.0.2.0/24)
   - Security Group: NishadInternsip-ALB-SG (Inbound HTTP Port 80 / HTTPS Port 443 from Internet / CloudFront)
   - Protocol: HTTP (TCP Port 80 Listener)
   - Action: Accepts /api/* traffic from CloudFront and load-balances across active EC2 targets in private subnets on target port 8000.

6. APP TIER AUTO SCALING GROUP (EC2 INSTANCES)
   - ASG Name: NishadInternsip-App-Tier-ASG
   - Network Location: AWS VPC - Private App Subnets with Egress (AZ-1: 10.0.10.0/24 | AZ-2: 10.0.11.0/24)
   - Security Group: NishadInternsip-App-Tier-SG (Inbound TCP Port 8000 ONLY from ALB-SG)
   - IAM Role: NishadInternsip-Avashya-EC2-App-Role
   - Protocol: HTTP / TCP Port 8000 (Python FastAPI / Gunicorn Web Application Server)
   - Action: Processes API requests, executes business logic, queries database, and manages file uploads.

7. AMAZON RDS POSTGRESQL DATABASE

   - Security Group: NishadInternsip-RDS-Database-SG (Inbound PostgreSQL Port 5432 ONLY from App-Tier-SG)

8. S3 GATEWAY VPC ENDPOINT

10. REGIONAL NAT GATEWAY & INTERNET GATEWAY (Egress Only)
